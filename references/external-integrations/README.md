# Sanctum Suite external integrations

This folder contains rebranded copies of the downloaded ZIP-derived reference projects.

Purpose:
- keep the original archive contents available
- avoid duplicating active application files already used by Sanctum Suite
- preserve a clean integration layer for future analysis, mapping and rebranding work

The source archives remain in `_archive_import`, and the folders here are intentionally renamed to `sanctum-suite-*` to keep the project identity consistent.
